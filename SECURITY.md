# Política de segurança

## Versões suportadas

Só a versão mais recente da branch `main` recebe correções, que é a mesma que está publicada.

## Como reportar uma vulnerabilidade

Se encontrar uma falha de segurança no SparkChat Web, **não abra uma issue pública**.

Use o [reporte privado de vulnerabilidades](https://github.com/Plovatto/SparkChat/security/advisories/new) do GitHub e conte:

- o que acontece e qual o impacto
- os passos para reproduzir
- a versão ou o commit em que testou

Como a criptografia das mensagens acontece no navegador, falhas que permitam ler mensagens, chaves ou anexos de outro usuário são as mais importantes para mim.

Eu respondo assim que possível e aviso quando a correção for publicada. Se quiser, seu nome entra nos créditos da correção.
