# Security policy

## Supported versions

Only the latest version of the `main` branch, which is the published version, receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/Plovatto/SparkChat/security/advisories/new).

Do not open public issues for security problems. Include enough detail to reproduce the problem, the affected commit, and the expected impact. Problems in the server belong in the [API repository](https://github.com/Plovatto/API-SparkChat/security/advisories/new).
